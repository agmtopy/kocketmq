### Gradle Wrapper冲突
**问题：** 多个gradle进程启动导致wrapper锁超时

**临时解决方案：**
```bash
# 方法1：等待其他gradle进程完成
# 方法2：杀掉gradle进程
pkill -f gradle

# 方法3：使用no-daemon选项
./gradlew --no-daemon :broker:test
```

**建议：** 在独立终端运行测试，避免并发gradle命令
