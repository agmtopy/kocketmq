## 🔧 技术亮点

### 1. Actor 模型 + Kotlin 协程

**优势**：
- 无锁并发设计，代码简洁
- 协程轻量级，支持高并发
- Channel 天然支持背压
- 更好的错误隔离

**实现**：
```kotlin
class CommitLogActor {
    private val requestChannel = Channel<Request>(Channel.UNLIMITED)

    suspend fun putMessage(message: MessageExt): PutMessageResult {
        return requestChannel.sendAndWait { ... }
    }
}
```

### 2. 两层存储架构

**CommitLog**：
- 所有消息顺序写入
- 内存映射文件（MMAP）
- 自动文件滚动

**ConsumeQueue**：
- Topic-Queue 索引
- 20 字节索引单元
- 快速消息定位
